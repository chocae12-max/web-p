# 웹 프로그래밍 7장 수업 요약

> **주제:** 자바스크립트 객체와 배열  

## 1. 서론

6장에서 변수와 함수 등 자바스크립트의 기본 문법을 배웠다면, 이번 장에서는 여러 값과 기능을 함께 다루는 **객체**를 살펴보았다. 배열, 날짜, 문자열, 수학 기능처럼 자주 쓰는 기본 객체를 익히고, 필요한 객체를 직접 만드는 방법을 학습했다.

## 2. 본론

### 2.1 객체의 구성과 종류

객체는 관련된 데이터를 나타내는 **프로퍼티**와 기능을 실행하는 **메소드**를 묶은 것이다. 예를 들어 계좌 객체는 소유자와 잔액을 프로퍼티로, 입금·출금·잔액 조회를 메소드로 가질 수 있다. 객체의 값은 `account.balance`처럼 
점(`.`)으로 접근하고, 기능은 `account.deposit(10000)`처럼 호출한다.

강의에서는 자바스크립트의 객체를 언어 자체에서 제공하는 기본 객체, HTML 문서의 요소를 나타내는 DOM 객체, 브라우저를 다루는 객체로 구분했다. 이번 장은 주로 기본 객체와 사용자 정의 객체에 집중한다.

### 2.2 배열: 여러 값을 하나로 다루기

배열은 여러 값을 순서대로 저장하며, `[]` 또는 `new Array()`로 만들 수 있다. 첫 번째 원소의 인덱스는 **0**이고, `length`로 배열의 길이를 확인한다. 반복문과 함께 사용하면 원소의 합계나 평균을 구하기 쉽다.

배열에는 `concat()`, `join()`, `reverse()`, `slice()`, `sort()` 같은 메소드가 있다. 이 중 어떤 메소드는 원본 배열을 바꾸고, 어떤 메소드는 새 배열이나 문자열을 돌려주므로 결과와 원본의 변화를 구별해야 한다.

### 2.3 자주 사용하는 기본 객체

| 객체 | 주요 용도 | 수업에서 다룬 예 |
| --- | --- | --- |
| `Array` | 여러 값 저장·처리 | 요일 목록, 온도의 평균 |
| `Date` | 날짜와 시간 처리 | 현재 시각 출력, 시간에 따른 배경색 |
| `String` | 문자열 처리 | 길이 확인, 검색·자르기·치환 |
| `Math` | 수학 계산 | 제곱근, 원주율, 난수 |

`Date`는 `new Date()`로 현재 날짜와 시간을 얻고, `getDate()`나 `getHours()`로 필요한 부분을 가져올 수 있다. 날짜를 숫자로 지정할 때 월은 **0부터 시작**하므로 3월을 나타내는 값은 2다. 문자열의 `length`는 길이를 알려주며,
`slice()`나 `replace()` 등의 메소드를 써도 원래 문자열 자체는 바뀌지 않는다. `Math`는 `new` 없이 `Math.sqrt()`, `Math.random()`, `Math.floor()`처럼 사용한다.

### 2.4 사용자 정의 객체

필요한 데이터와 동작을 직접 묶을 때는 `new Object()`로 빈 객체를 만든 뒤 항목을 추가하거나, 중괄호 `{ }`로 프로퍼티와 메소드를 한 번에 작성한다. 수업에서는 계좌 객체에 잔액을 저장하고 입금·출금 메소드에서 `this.balance`를 변경했다.
같은 형태의 객체를 여러 개 만들 때는 `Student`나 `Account`처럼 생성자 함수를 정의하고 `new`로 객체를 생성하는 방법도 다루었다.

## 3. 결론

객체는 관련된 값과 동작을 하나로 묶어 프로그램을 구성하기 쉽게 한다. 배열로 여러 데이터를 처리하고, `Date`·`String`·`Math`의 기능을 활용하면 자주 필요한 작업을 직접 처음부터 만들지 않아도 된다. 사용자 정의 객체와 생성자 함수를 이해하면
비슷한 데이터와 기능을 가진 대상을 일관된 방식으로 표현할 수 있다.
