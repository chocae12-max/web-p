# 웹 프로그래밍 10장 수업 요약

> **주제:** 브라우저 객체 모델(BOM)과 브라우저 제어  
## 1. 서론

8장에서는 DOM으로 웹 문서의 요소를 바꾸고, 9장에서는 이벤트에 반응하는 방법을 배웠다. 이번 장은 문서 바깥의 브라우저 환경을 다루는 **BOM(Browser Object Model)**을 살펴본다. 새 창을 열고, 일정 시간이 지난 뒤 작업을 실행하며,
현재 주소와 방문 기록 등을 이용하는 방법이 중심이다.

## 2. 본론

### 2.1 BOM과 주요 객체

DOM이 HTML 문서의 내용과 구조를 표현한다면, BOM은 브라우저 창과 그 주변 정보를 다룬다. 최상위 `window` 객체를 중심으로 다음 객체를 사용할 수 있다.

| 객체 | 주요 역할 | 예시 |
| --- | --- | --- |
| `window` | 창·탭 제어, 타이머, 스크롤, 인쇄 | `open()`, `setTimeout()` |
| `location` | 현재 페이지 주소 확인 및 이동 | `location.href`, `assign()` |
| `navigator` | 브라우저와 실행 환경 정보 | `language`, `onLine` |
| `screen` | 화면 장치의 크기와 색상 정보 | `width`, `height` |
| `history` | 방문 기록을 통한 앞뒤 이동 | `back()`, `forward()` |

브라우저가 제공하는 정보나 세부 동작은 환경에 따라 달라질 수 있다. 따라서 BOM 기능을 사용할 때는 실제 브라우저에서 결과를 확인하는 것이 필요하다.

### 2.2 창 열기와 화면 조작

`window.open("주소", "이름", "속성")`으로 새 창이나 탭을 열 수 있다. 이름을 지정하면 같은 이름의 창을 다시 활용할 수 있고, `_self`는 현재 창, `_blank`는 새 창이나 탭을 대상으로 한다. `close()`로 창을 닫는 방법도 배웠지만,
브라우저의 보안 정책에 따라 스크립트로 열지 않은 창은 닫히지 않을 수 있다.

`moveBy()`와 `resizeTo()` 등은 창의 위치나 크기를 조절하고, `scrollBy()`와 `scrollTo()`는 페이지의 스크롤 위치를 바꾼다. 강의에서는 일정 간격으로 화면을 조금씩 내리는 자동 스크롤을 실습했다. 인쇄는 `print()`로 시작하며,
`beforeprint`와 `afterprint` 이벤트로 인쇄 전후의 화면 표시를 바꿀 수 있다.

### 2.3 타이머로 실행 시점 정하기

| 방식 | 동작 | 중단 방법 |
| --- | --- | --- |
| `setTimeout(함수, 시간)` | 지정한 시간이 지난 뒤 한 번 실행 | `clearTimeout(아이디)` |
| `setInterval(함수, 시간)` | 지정한 간격으로 반복 실행 | `clearInterval(아이디)` |

시간은 밀리초 단위다. 수업의 예제에서는 이미지 위에 마우스를 일정 시간 올려두면 다른 사이트로 이동하도록 `setTimeout()`을 사용하고, 마우스를 떼면 타이머를 취소했다. `setInterval()` 예제에서는 텍스트를 반복해서 움직이고 클릭하면 반복을 멈췄다.

### 2.4 주소, 환경 정보와 방문 기록

`location` 객체는 현재 URL의 프로토콜·호스트·경로 등을 나타내며 다른 주소로 이동할 때도 사용한다. `navigator`로는 브라우저의 언어와 접속 상태 같은 정보를, `screen`으로는 화면 크기 등의 정보를 확인한다.
`history.back()`과 `history.forward()`는 사용자가 방문한 기록을 따라 이전 또는 다음 페이지로 이동한다.

## 3. 결론

BOM을 이용하면 JavaScript가 HTML 문서의 내용뿐 아니라 브라우저 창과 실행 환경에도 접근할 수 있다. 이번 장의 핵심은 목적에 맞는 객체를 고르는 것이다. 화면 내용을 바꿀 때는 DOM을, 창·주소·시간·방문 기록을 다룰 때는 각각의 BOM 기능을 활용한다.
