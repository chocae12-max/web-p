# 웹 프로그래밍 6장 수업 요약

> **주제:** 자바스크립트의 기본 문법과 제어 구조  
> **자료:** 「명품 웹 프로그래밍」 6장 강의자료(65쪽)

## 1. 서론

앞선 장까지는 HTML로 내용을 만들고 CSS로 화면을 꾸미는 방법을 배웠다. 이번 장에서는 웹 페이지에 동작을 추가하는 자바스크립트를 다룬다. 코드를 작성하는 위치부터 변수, 연산자, 조건문, 반복문, 함수까지 프로그램을 만드는 데 필요한 기본 문법을 살펴보았다.

## 2. 본론

### 2.1 웹 페이지에서 자바스크립트 사용하기

자바스크립트는 사용자의 동작에 반응하거나 웹 페이지의 내용을 바꾸는 데 사용된다. 코드는 HTML의 `<script>` 태그에 작성하거나 별도의 `.js` 파일을 불러와 사용할 수 있다. HTML 태그의 이벤트 속성에도 간단한 코드를 넣을 수 있다. 수업에서는 `document.write()`로 내용을 출력하고, `prompt()`, `confirm()`, `alert()`로 사용자에게 값을 묻거나 메시지를 보여주는 방법을 실습했다.

### 2.2 변수와 데이터

변수는 프로그램에서 사용하는 값을 저장한다. `let`은 값을 다시 넣을 수 있는 변수를 선언하고, `const`는 재할당하지 않을 값을 선언한다. 변수의 사용 범위는 선언한 위치에 따라 달라지므로 전역 변수, 함수 안의 지역 변수, 블록 안의 변수를 구별해야 한다.

자바스크립트에서 다루는 값에는 숫자, 문자열, 참·거짓을 나타내는 불리언 값 등이 있다. 문자열은 따옴표로 감싸고, 문자 안에 따옴표나 줄 바꿈 같은 특수한 내용을 넣을 때는 이스케이프 문자를 사용한다.

### 2.3 연산자와 식

| 종류 | 역할 | 예시 |
| --- | --- | --- |
| 산술 연산 | 수치 계산 | `+`, `-`, `*`, `/`, `%` |
| 대입·증감 | 값 저장 또는 1씩 변경 | `=`, `+=`, `++`, `--` |
| 비교 | 두 값의 관계를 판단 | `>`, `<=`, `===` |
| 논리 | 여러 조건을 결합 | `&&`, `||`, `!` |
| 조건 연산 | 조건에 따라 값 선택 | `조건 ? 값1 : 값2` |
| 문자열 연결 | 문자열 이어 붙이기 | `"웹" + "페이지"` |

강의에서는 비트 단위의 논리 연산과 시프트 연산도 소개했다. 연산자를 사용할 때는 각 연산의 결과와 우선순위를 확인해야 하며, 문자열이 포함된 `+`는 수치 덧셈 대신 문자열 연결로 작동할 수 있다.

### 2.4 조건문과 반복문

`if`와 `if-else`는 조건에 따라 다른 코드를 실행한다. 여러 값 중 하나를 고를 때는 `switch`와 `case`를 사용할 수 있으며, 필요한 위치에 `break`를 넣어 다음 경우로 실행이 이어지는 것을 막는다.

반복 작업에는 `for`, `while`, `do-while`을 사용한다. `for`는 반복 횟수를 관리하기 편하고, `while`은 조건을 먼저 검사한다. `do-while`은 본문을 실행한 다음 조건을 검사하므로 적어도 한 번 실행된다. 반복 중 `break`는 반복을 끝내고 `continue`는 현재 회차의 나머지를 건너뛴다.

### 2.5 함수

함수는 여러 곳에서 사용할 동작을 하나로 묶는다. `function`으로 이름과 매개변수를 정하고, `return`으로 결과를 돌려줄 수 있다. 수업의 덧셈 함수와 구구단 출력 함수는 같은 계산을 필요할 때마다 호출하는 예시다. `parseInt()`와 `isNaN()`처럼 값을 처리하거나 검사하는 함수도 함께 다루었다.

## 3. 결론

자바스크립트를 사용하면 정적인 웹 페이지에 계산과 사용자 반응을 추가할 수 있다. 변수에 값을 저장하고 연산자로 처리한 뒤, 조건문과 반복문으로 실행 흐름을 제어하며, 함수로 작업을 묶는 것이 이번 장의 핵심이다. 이러한 문법은 이후 웹 페이지의 요소를 직접 조작하는 내용을 배우기 위한 기초가 된다.
