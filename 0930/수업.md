# 웹 프로그래밍 5장 수업 요약

> **주제:** CSS3의 배치와 동적 효과  
## 1. 서론

4장에서는 CSS로 색상, 글꼴, 박스의 모양을 꾸미는 방법을 배웠다. 이번 장에서는 요소가 화면의 어디에 놓일지 정하고, 리스트·표·폼의 표현을 바꾸며, 애니메이션과 전환으로 움직이는 효과를 만드는 방법을 살펴보았다.

## 2. 본론

### 2.1 박스 유형과 위치

HTML 요소는 기본적으로 작성 순서에 따라 배치된다. CSS의 `display`를 사용하면 블록 요소와 인라인 요소의 표시 방식을 바꿀 수 있다. `block`은 한 줄을 차지하고,
`inline`은 다른 내용과 같은 줄에 놓이며, `inline-block`은 같은 줄에 놓이면서 폭과 높이도 조절할 수 있다. `none`은 요소가 차지하는 공간까지 없앤다.

| 속성 또는 값 | 주요 역할 |
| --- | --- |
| `position: static` | 일반적인 문서 흐름에 따라 배치 |
| `position: relative` | 원래 위치를 기준으로 이동 |
| `position: absolute` | 배치 기준이 되는 조상 요소를 기준으로 위치 지정 |
| `position: fixed` | 화면의 정해진 위치에 고정 |
| `float` | 요소를 왼쪽이나 오른쪽으로 띄워 배치 |
| `z-index` | 겹친 요소의 앞뒤 순서 지정 |

`top`, `right`, `bottom`, `left`는 위치를 조절하고, `visibility`는 요소를 숨기거나 보이게 한다. `overflow`는 내용이 박스 크기를 넘었을 때 잘라내거나 스크롤을 표시하는 등의 처리를 담당한다.
이 속성들은 배치 방식에 따라 동작이 달라지므로 적용 기준을 먼저 확인해야 한다.

### 2.2 리스트·표·폼 꾸미기

리스트는 `list-style-type`으로 마커의 모양을, `list-style-position`으로 마커가 놓일 위치를 정한다. 마커에 이미지를 사용할 수도 있으며, 마커를 없애고 배경색과 간격을 조절하면 목록을 메뉴처럼 표시할 수 있다.

표에서는 셀의 테두리, 크기, 여백과 정렬을 조절한다. 행마다 다른 배경색을 넣거나 `:hover`로 마우스가 올라간 행의 색을 바꾸면 내용을 읽기 편해진다. 입력 폼에도 CSS를 적용해 입력창과 버튼의 글꼴, 테두리, 상태별 모양을 바꿀 수 있다.

### 2.3 애니메이션, 전환과 변환

CSS만으로도 요소의 모양을 동적으로 바꿀 수 있다. 세 방법의 역할은 다음과 같다.

| 방법 | 설명 | 예시 |
| --- | --- | --- |
| 애니메이션 `animation` | `@keyframes`로 시간에 따른 여러 상태를 정함 | 글자색을 주기적으로 변경 |
| 전환 `transition` | 속성값이 바뀔 때 변화를 일정 시간에 걸쳐 보여줌 | 마우스를 올리면 글자가 서서히 커짐 |
| 변환 `transform` | 요소를 기하학적으로 바꿈 | 회전·기울이기·이동·확대 |

수업에서는 `@keyframes`로 글자 크기가 줄어드는 애니메이션을 만들고, `:hover`와 `transition`을 결합해 글자가 점차 커지는 효과를 실습했다. `rotate()`, `skew()`, `translate()`, `scale()`로 요소의 모양과 위치를 바꾸는 예도 다루었다.

## 3. 결론

CSS 배치는 HTML 작성 순서와 별개로 요소의 표시 방식과 위치를 정하는 작업이다. `display`와 `position`의 차이를 알고, 겹침과 넘치는 내용을 적절히 처리해야 원하는 화면을 만들 수 있다.
여기에 애니메이션·전환·변환을 더하면 JavaScript 없이도 간단한 움직임과 반응을 구현할 수 있다.
