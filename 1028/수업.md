# 웹 프로그래밍 9장 수업 요약

> **주제:** JavaScript 이벤트와 사용자 입력 처리 

## 1. 서론

웹 페이지는 클릭, 키 입력, 마우스 이동, 문서 로딩처럼 여러 상황에 반응한다. 이번 장에서는 이런 상황을 **이벤트**라고 부르며, 이벤트가 발생했을 때 실행되는 함수를 등록하고 이벤트 정보를 이용하는 방법을 배웠다.
이를 통해 8장에서 익힌 DOM 조작을 사용자의 행동과 연결할 수 있다.

## 2. 본론

### 2.1 이벤트 리스너 등록

이벤트를 처리하는 함수를 **이벤트 리스너**라고 한다. 수업에서는 HTML 태그의 이벤트 속성에 코드를 쓰거나, DOM 객체의 `onclick`과 같은 프로퍼티에 함수를 지정하거나, `addEventListener()`로 등록하는 방법을 소개했다.
이름이 없는 익명 함수를 리스너로 사용할 수도 있다. 예를 들어 버튼의 `click` 리스너를 등록하면 사용자가 버튼을 누를 때 해당 코드가 실행된다.

### 2.2 이벤트 객체와 기본 동작

리스너는 이벤트 객체를 전달받아 어떤 일이 일어났는지 확인할 수 있다. `type`은 이벤트 종류, `target`은 이벤트가 발생한 요소, `currentTarget`은 현재 리스너가 실행되는 요소를 나타낸다.
마우스의 위치나 누른 키와 같은 정보도 이벤트 종류에 따라 확인할 수 있다.

링크를 클릭하면 이동하고 폼을 제출하면 전송하는 것처럼 요소에는 기본 동작이 있다. 필요한 경우 `event.preventDefault()`로 기본 동작을 취소할 수 있다. 이벤트가 부모와 자식 요소 사이를 전달되는 과정은 **캡처 단계**와 **버블 단계**로 나뉘며,
`stopPropagation()`은 이벤트 전달을 중단하는 데 사용한다.

### 2.3 주요 이벤트와 활용

| 범주 | 대표 이벤트 | 수업의 활용 사례 |
| --- | --- | --- |
| 마우스 | `click`, `mousemove`, `contextmenu` | 계산기 버튼, 마우스 위치 확인 |
| 로딩 | `load` | 문서나 이미지가 준비된 뒤 작업 실행 |
| 입력 포커스 | `focus`, `blur` | 입력창을 선택하거나 벗어날 때 확인 |
| 선택 변경 | `change` | 선택한 과일에 맞는 이미지 출력 |
| 키보드 | `keydown`, `keyup` | 누른 키 확인, 방향키로 표의 셀 이동 |
| 폼 | `submit`, `reset` | 전송 또는 초기화 전에 입력 검사 |

라디오 버튼과 체크박스는 `checked`로 선택 여부를 확인할 수 있다. `<select>`는 `selectedIndex`와 `options`로 현재 항목을 알아낸다. 강의의 예제에서는 체크된 물품의 가격을 더하거나 빼고, 선택한 과일에 따라 이미지의 `src`를 바꾸었다.

### 2.4 로딩과 입력 시점의 중요성

HTML 요소나 이미지가 준비되기 전에 그 객체를 사용하면 원하는 값을 얻지 못할 수 있다. 문서의 `load` 이벤트나 이미지의 로딩 완료를 확인한 뒤 작업해야 하는 이유다. 키 이벤트에서도 키를 누르는 순간과 떼는 순간이 다르므로,
필요한 시점에 맞는 이벤트를 선택해야 한다.

## 3. 결론

이벤트는 사용자와 웹 페이지를 연결한다. 리스너를 등록하고 이벤트 객체에서 필요한 정보를 읽으면 클릭, 선택, 키 입력에 맞추어 DOM을 변경할 수 있다. 기본 동작의 취소와 이벤트 전달 과정까지 이해하면
여러 요소가 겹친 페이지에서도 원하는 반응을 구현하기 쉽다.
