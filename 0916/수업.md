# 웹 프로그래밍 3장 수업 요약

> **주제:** HTML5의 시맨틱 구조와 웹 폼  

## 1. 서론

이번 장에서는 웹 페이지의 내용을 의미에 맞게 구분하는 시맨틱 태그와 사용자 입력을 받는 웹 폼을 배웠다. HTML은 화면에 내용을 표시할 뿐 아니라, 각 영역이 어떤 역할을 하는지 나타내고 사용자의 정보를 서버에 전달하는 데도 쓰인다.

## 2. 본론

### 2.1 시맨틱 태그와 문서 구조

과거에는 `<div>`나 표를 이용해 화면을 나누는 경우가 많았지만, 태그 이름만으로는 해당 영역의 의미를 알기 어려웠다. HTML5의 **시맨틱 태그**는 머리말, 메뉴, 본문, 부가 정보 등을 의미에 따라 표시한다. 이러한 구조는 문서를 이해하고 필요한 정보를 찾는 데 도움을 준다. 화면의 색상과 배치는 시맨틱 태그 자체가 정하지 않으므로 CSS로 지정한다.

| 태그 | 문서에서 맡는 역할 |
| --- | --- |
| `<header>` | 페이지나 구역의 머리말 |
| `<nav>` | 메뉴와 주요 링크의 묶음 |
| `<section>` | 주제에 따른 장이나 절 |
| `<article>` | 독립적으로 읽을 수 있는 내용 |
| `<aside>` | 본문에 덧붙이는 정보 |
| `<footer>` | 저자·저작권 등의 꼬리말 |

`<figure>`와 `<figcaption>`은 그림·코드 등에 설명을 붙일 때 활용할 수 있다. `<details>`와 `<summary>`는 펼쳐 볼 수 있는 상세 내용을 만든다. `<mark>`, `<time>`, `<meter>`, `<progress>` 등은 텍스트의 의미나 수치·진행 상태를 표현한다.

### 2.2 웹 폼의 작동

**웹 폼**은 로그인, 검색, 신청처럼 사용자에게 정보를 입력받는 부분이다. `<form>` 안에 입력 요소를 배치하며, `action`은 데이터를 처리할 위치, `method`는 GET 또는 POST와 같은 전송 방식을 지정한다. 사용자가 제출 버튼을 누르면 브라우저가 입력 값을 전송한다.

### 2.3 입력 요소의 종류

| 입력 목적 | 대표 태그 또는 속성 |
| --- | --- |
| 한 줄 텍스트·비밀번호 | `<input type="text">`, `<input type="password">` |
| 여러 줄 텍스트 | `<textarea>` |
| 여러 항목 선택·하나만 선택 | `checkbox`, `radio` |
| 목록에서 선택 | `<select>`와 `<option>` |
| 직접 입력하며 추천 목록 보기 | `<datalist>` |
| 날짜·시간·숫자·범위 | `date`, `time`, `number`, `range` |
| 이메일·주소·검색어 | `email`, `url`, `search` |

체크박스는 여러 항목을 선택할 때, 같은 `name`을 가진 라디오 버튼은 한 항목만 선택할 때 적합하다. `<label>`로 설명 문구와 입력 요소를 연결하면 문구를 눌러도 해당 요소를 선택할 수 있다. `placeholder`는 입력 예시를 보여주며, `<fieldset>`과 `<legend>`는 관련 입력 항목을 한 그룹으로 묶는다.

## 3. 결론

시맨틱 태그를 쓰면 웹 문서의 각 부분이 어떤 의미인지 더 분명해진다. 웹 폼은 그 문서 안에서 사용자와 상호작용하며 필요한 정보를 입력받는 역할을 한다. 이 장의 핵심은 화면에 보이는 모양만 생각하기보다, 내용의 의미와 입력 목적에 맞는 태그를 선택하는 것이다.
