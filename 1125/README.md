# 11월25일 저녁 신청 받기

Google Apps Script와 Google Sheets로 만든 신청 웹앱입니다.
이름, 음식, 하고 싶은 말을 입력하면 스프레드시트에 저장되고 "답장 감사합니다."가 표시됩니다.

## 구성

- `Code.gs`: 화면 제공 및 구글 시트에 입력 내용 저장
- `index.html`: 신청 화면

## 실행

1. 새 구글 스프레드시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs`를 붙여 넣고 HTML 파일을 `index`라는 이름으로 만들어 `index.html`을 붙여 넣습니다.
3. **배포 → 새 배포 → 웹 앱**에서 실행 사용자를 **나**로 선택하고 배포합니다.
4. 배포된 웹 앱 주소에서 신청한 뒤 연결된 시트에 행이 추가되는지 확인합니다.

GitHub에는 압축파일 대신 압축을 푼 `Code.gs`, `index.html`, `README.md`를 올려야 코드가 보입니다.
시트에 저장되는 기능은 Apps Script 웹 앱 주소에서 실행됩니다.
