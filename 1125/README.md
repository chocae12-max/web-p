# 조재완 소프트웨어 포트폴리오

소프트웨어학과 소개, 전자기기 관심 분야, 일본 유학 및 프로그래밍 학습 목표를 담은 웹 포트폴리오입니다.

## 구성

- `Code.gs`: Apps Script 웹 앱에서 HTML 화면 제공
- `index.html`: 포트폴리오 화면 및 브라우저 동작

## Apps Script 실행

1. Apps Script 프로젝트의 `Code.gs` 내용을 해당 파일로 바꿉니다.
2. HTML 파일을 `index`라는 이름으로 만들어 `index.html` 내용을 넣습니다.
3. 저장 후 **배포 → 새 배포 → 웹 앱**으로 주소를 만듭니다.

GitHub에는 압축파일 대신 압축을 푼 `Code.gs`, `index.html`, `README.md`를 올려야 코드가 보입니다.
